# Study Habits and Student Well-being

A beginner project for organizing a fictional psychology class activity.

This repository is created by a small student team to organize our fictional psychology project and to show how the project changes over time using GitHub commits. All data is fictional.

## 1. Project Purpose
To understand the connection between study habits (like study time, breaks, sleep) and student well-being (like stress and focus).

## 2. Research Questions (Fictional)
- How does daily study time affect stress level?
- Do short breaks during study improve well-being?
- What are common fictional study habits among students?

## 3. Team Roles (Fictional Names)
- Member A: Notes and Research
- Member B: Data Organization  
- Member C: Presentation Design

## 4. Fictional Data Example (No Real Data)
We will NOT use any real student data. Only fake examples for learning:
- Example 1: Study = 2 hours, Sleep = 7 hours, Well-being Score = 6/10
- Example 2: Study = 4 hours, Sleep = 8 hours, Well-being Score = 8/10

## 5. How We Will Use This Repository
- We will add notes in folders
- We will use commits to show changes
- We will keep everything organized
